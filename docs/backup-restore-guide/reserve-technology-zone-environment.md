# Reserve Technology Zone environment

You will also need to reserve two (2) IBM Fusion environments in IBM Technology Zone (once you have access). Refer to the IBM Fusion - IBM Technology Zone Setup Guide documentation ([IBM Fusion - IBM Technology Zone Setup Guide.pdf](https://ibm.seismic.com/Link/Content/DC2qDg9cGBM8H8FXb2qVQmQGVVVj)) for step-by-step instructions on how to create an IBM account and reserve an IBM Fusion environment in IBM Technology Zone. Once you have an environment provisioned, you can begin working your way through the exercises found in this guide.
> IMPORTANT: Two (2) IBM Fusion environments will be used during this lab. It is helpful to reserve both environments at the same time.
> NOTE: If using the same environment from the Installation and Configuration hands-on lab, it may be useful to change the default storageClass from managed-nfs-storage to ibm-storagecluster-ceph-rbd.
