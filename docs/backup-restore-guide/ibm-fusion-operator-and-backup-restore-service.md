# IBM Fusion Operator and Backup & restore service

To complete the activities included in this lab, the IBM Fusion operator and IBM Fusion backup & restore service need to be installed. Follow the instructions included in the IBM Fusion - Installation and Configuration Lab Guide document ([IBM Fusion - Installation and Configuration Lab Guide.pdf](https://ibm.seismic.com/Link/Content/DC9PRjHpgppqDGhBjJB4dg3JHQMB)) to deploy these services.
> IMPORTANT: The steps to install and configure the IBM backup & restore service should only be completed on one of the clusters to support installing the IBM Backup & restore agent on the second OCP cluster.
