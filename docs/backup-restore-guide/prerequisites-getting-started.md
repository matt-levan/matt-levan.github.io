# Prerequisites & Getting Started

You will need an IBM account and corresponding IBMid to gain access to IBM Technology Zone.
In addition, you must be familiar with the Linux operating system, as well as know how to use the command line interface to execute basic Linux commands such as kubectl, oc, exit, ls, mkdir, ssh, sudo, and curl (to name few). Ideally, you should also have some experience working with the Red Hat OpenShift Graphical User Interface (GUI) and executing Red Hat OpenShift Container Platform and Kubernetes command line interface (CLI) commands. If you need experience using Linux, Kubernetes and Red Hat OpenShift Container Platform, it is highly recommended that you complete the following Red Hat courses before you attempt to work through the exercises in this lab.
Red Hat Courses:
- [DO080 – Containers, Kubernetes and Red Hat OpenShift Technical Overview](https://training-lms.redhat.com/sso/saml/auth/rhopen?RelayState=deeplinkoffering%3D43022363) (https://training-lms.redhat.com/sso/saml/auth/rhopen?RelayState=deeplinkoffering%3D43022363)
- [DO180 – Red Hat OpenShift Administration I: Managing Containers and Kubernetes](https://training-lms.redhat.com/sso/saml/auth/rhopen?RelayState=deeplinkoffering%3D46105986) (https://training-lms.redhat.com/sso/saml/auth/rhopen?RelayState=deeplinkoffering%3D46105986)
- [DO280 – Red Hat OpenShift Administration II: Operating a Production Kubernetes Cluster](https://training-lms.redhat.com/sso/saml/auth/rhopen?RelayState=deeplinkoffering%3D46105987) (https://training-lms.redhat.com/sso/saml/auth/rhopen?RelayState=deeplinkoffering%3D46105987)
